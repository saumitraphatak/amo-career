## Headline finding: `llms.txt`/`llms-full.txt`/`CLAUDE.md`/`README.md` had drifted stale again

The site grew from 28 to 32 pages since the last technical audit (four new pages: `quantinuum-vs-ionq.html`, `google-vs-ibm.html`, and `psiquantum-vs-xanadu.html` — three company-comparison deep dives added 2026-09-22 through -26 — plus `start-here.html`, a site-map/navigation page added even more recently). `sitemap.xml` was correctly kept in sync (32/32 URLs, confirmed by a scripted diff against the actual `pages/*.html` file list), but the AI-discoverability layer and the two project docs were not:

- **`llms.txt` and `llms-full.txt` were each missing 6 of 32 pages** (`google-vs-ibm.html`, `laser-cooling.html`, `psiquantum-vs-xanadu.html`, `quantinuum-vs-ionq.html`, `rb87-vs-yb171.html`, `start-here.html`) — confirmed by a scripted diff of every `pages/*.html` link referenced in each file against the real `pages/` directory listing. Both files still claimed "28 tool and content pages" in their opening paragraph. Since these two files exist specifically to feed AI research tools and RAG pipelines (per their own stated purpose and per the 2026-09-16 report's own framing), a visitor's or AI system's search for any of these 6 pages via `llms.txt` would come up empty. Fixed: added a full entry for each missing page to `llms.txt` (in the section matching its category — the new comparison pages joined `qc-landscape.html` under "Quantum Computing," `laser-cooling.html` joined "Research Tools" next to its simulator sibling, `start-here.html` joined "Home"), added matching sections to `llms-full.txt` (three new `### <Company A> vs <Company B>` entries under "CAREER & REFERENCE PAGES" describing each page's actual section structure, `pages/decoherence-lab.html` and the 4 new pages added to the `SITE STRUCTURE` file tree — `decoherence-lab.html` had its own `## TOOL 23` section already but had been left out of the tree listing itself — and a short note explaining why `start-here.html` has no dedicated `## TOOL` section of its own), and corrected both files' page-count language to 32 pages / 31 tools. Re-verified with the same scripted diff: both files now list all 32 pages with zero gaps.
- **`CLAUDE.md`'s entire `NAV` object documentation code block (the "Single Source of Truth" reference copy) had drifted from the real `js/main.js` far more badly than just missing the 4 new pages** — every single accent color in it was stale, predating the color remap the 2026-09-17 design audit documented (the real site now cycles three ink colors, `#a13c1c`/`#2c4a63`/`#3f5d3f`, across all tool cards; `CLAUDE.md`'s copy still showed the old one-rainbow-color-per-tool scheme from before that remap), and it was also missing `decoherence-lab.html` entirely from the `quantum` array (not just the 3 new `career` entries). Rather than hand-patch a long-stale block, extracted the current `NAV` object verbatim from `js/main.js` by script and replaced `CLAUDE.md`'s copy wholesale — this is a pure documentation sync with no functional effect, and scripting the extraction (rather than retyping ~40 lines of emoji/hex-color-laden JS by hand) avoids transcription risk. `CLAUDE.md`'s separate ASCII directory tree and its "Page count is 28" note were also updated (32, with the growth history appended) and the tree extended with the 4 new pages.
- **`README.md`** had the same three gaps in miniature: its "28 interactive research tools" intro line, its tool table (missing rows for the 3 comparison pages — `start-here.html` isn't in this table by design, matching its exclusion from `NAV.tools`), and its project-structure ASCII tree (missing `decoherence-lab.html` from the Quantum line and the 3 comparisons + `start-here.html` from Career). All updated to match current reality.

## Other findings — fixed

- **`pages/vacuum-systems.html`'s `twitter:title` read "Vacuum Systems"** — missing the word "Guide" that appears everywhere else on the page (`<title>`, `og:title`, and the JSON-LD `headline` all correctly say "Vacuum Systems Guide"). All three were trimmed to ≤160 characters (160, 154, and 142 respectively) while preserving every substantive fact (both companies named, the hardware modality, and the comparison's actual scope) — only softened qualifiers ("in-depth, heavily-referenced," "the two leading") were cut.
- **`pages/start-here.html`'s meta description was 169 characters** (9 over) — trimmed "plus the full recommended-order paths" to "plus recommended-order paths," landing at exactly 160.

Fixed for consistency and strict HTML validity (an unescaped `&` in an attribute value is tolerated by browsers but is not well-formed HTML).

# Cross-Page Consistency Audit — September 2026

Scope: the wayfinding elements that appear identically-styled on nearly every page — hero "eyebrow" badges (icon + category + sequence number + title), `BreadcrumbList` JSON-LD category names, and the "kind" taxonomy used in `NAV`/home cards — checked for internal consistency *across* the 28 tool pages rather than correctness on any single page. This is audit #7 of the original 8-item menu (cross-page consistency); the technical/SEO/consistency audit already covered title-tag formatting, meta-description length, and several other page-level consistency items and isn't re-covered here except where a note below builds directly on it.

Method: extracted every page's hero-eyebrow text and CSS class, every `BreadcrumbList` category name, and the `kind:` field from every `NAV` entry in `js/main.js`, then diffed each set for gaps, duplicates, and wording drift within each of the four site categories (Build, Trap/Image & Cool, Quantum, Career). Cross-checked every candidate finding against `docs/page-notes/*.md` and the existing audit reports before touching anything, since several likely-looking "bugs" in this area turned out to be already-documented deliberate decisions (see "Already known, not re-flagged" below).

## Fixed

- **`laser-cooling.html` and `absorption-imaging.html` both carried the eyebrow badge "Trap, Image & Cool 05."** The category's other five pages number 01→04, 06 cleanly (imaging-calculator 01, release-recapture 02, tof-calculator 03, lab-calculators 04, cooling-simulator 06), so this was a genuine duplicate, not a documented exception like the Quantum category's "01" (see below). Bumped `laser-cooling.html` to `06`, which pushed `cooling-simulator.html` (previously `06`) to `07` — the category now reads 01-07 in exact `NAV.trapImageCool` order with no gaps or repeats.
- **`remote-entanglement.html`'s eyebrow read "Quantum Computing · Deep Dive"** — no sequence number, and "Quantum Computing" instead of the shorter "Quantum" every one of its five Quantum-category siblings uses (learn-quantum, rydberg-calculator, fidelity-budget, rb-explorer, dd-playground all read "Quantum NN"). It was also the only sibling whose eyebrow named the page's `kind` ("Deep Dive") instead of its title, unlike every other page's "`<icon> <Category> <NN> · <Page Title>`" pattern. Changed to "Quantum 06 · Remote Entanglement Generation" — completes the category's 01-06 run and matches the page's own `<h1>` and breadcrumb title.
- **`decoherence-lab.html`'s `BreadcrumbList` JSON-LD named its category "Quantum Computing"** while all five sibling Quantum pages' breadcrumbs say "Quantum." This is the same insertion artifact the technical audit already caught in this page's hero eyebrow (that one's since been fixed to "Quantum 01" — confirmed on this pass); the breadcrumb copy just wasn't caught at the time because it lives in a different part of the page. Corrected to "Quantum" to match.

All four fixes are one-line text changes with no layout, CSS, or JS impact. Tag-balance (div/ul/li/tr/td/section/table/span) was checked on every file touched and came back balanced; `tests/formula_regression.py` was re-run after the batch and stayed green (11/11 PASS).

## Flagged, not changed — needs your call

- **`rb87-vs-yb171.html` has no hero eyebrow badge at all.** It's the 4th page in the Career category (after amo-groups "Career 01," paper-syllabus "Career 02," qc-landscape "Career 03"), so a consistent site would show "Career 04" here, but the page never had one — its own page-note describes a bespoke two-column "Rb87 card / Yb171 card" hero layout rather than the single-column text hero every eyebrow-bearing page uses. That could be a deliberate design difference for this one comparison-style page, or a plain oversight from when the eyebrow convention was added to other pages after this one was built. Adding a badge means picking where it goes in a hero layout that wasn't designed around one — a small design decision, not a one-line text fix, so I left it for you to decide rather than bolting one on.
- **The eyebrow component itself is implemented three different ways across the site**: `<div class="page-hero-eyebrow">` (20 of 28 pages, the majority pattern), `<div class="page-hero-label">` (rb-explorer.html only), `<div class="pill">` (dd-playground.html only), and `<div class="page-eyebrow">` wrapping two `<span class="page-tag">` chips (amo-groups.html, paper-syllabus.html). All four render a visually similar badge, so this isn't a visitor-facing bug, but it means a future shared-style change (e.g. the design audit's still-open theme-default question) has to be applied in up to four places instead of one. Not touched — unifying the markup means confirming each variant's CSS renders identically first, which is a design-audit-level check I didn't want to do as a side effect of a wayfinding-numbering pass.

## Already known, not re-flagged

- **The Quantum category has two pages both numbered "01"** (`decoherence-lab.html` and `learn-quantum.html`). This looked identical in shape to the duplicate I fixed above, but it's explicitly documented as deliberate: `decoherence-lab.md` records it was inserted as the first entry in `NAV.quantum` at Saumitra's request, and the technical audit's own note says the *number* wasn't bumped on purpose when that insertion happened (only the category-label wording drift was flagged as unintentional, and that's now fixed). Left as-is.
- **`vacuum-systems.html`'s and `laser-planner.html`'s References sections** were flagged by the technical audit as missing the numbered `<span class="accent">` styling every sibling References heading has. Checked both on this pass — they now carry the numbered span (`08` and `06` respectively), so this was already fixed since that report was written. No action needed.
- **`decoherence-lab.html` having no References section at all**, also from the technical audit, is likewise already resolved — it now has a numbered "08 References & Further Reading" section.

## Confirmed clean (no action)

- **Build category (10 pages): eyebrow numbers run 01→10 with no gaps or duplicates** (atom-library through tweezer-designer), in exact `NAV.build` order.
- **`NAV`'s `kind:` taxonomy (Calculator, Guide, Simulator, Deep dive, Reference, Design tool, Design lab, Imaging lab, Learning path, Career map, Landscape, Syllabus)** — checked all 27 values for capitalization consistency; every one follows the same "Capitalized-first-word, lowercase-rest" pattern with no stray casing.
- **Every page's `<link rel="canonical">`, `og:image`/`og:image:width/height/alt`, and `twitter:card`/`twitter:title`/`twitter:description`/`twitter:image` tags are present on all 28 tool pages plus `home.html`** — no page is missing any of these (404.html correctly has no canonical, since it isn't a real indexable page).
- **`<html lang="en">` is present on every page site-wide**, including `home.html`, `404.html`, and `index.html`.
- **No page anywhere has a `<meta name="robots">` tag** — this is a uniform absence (relying on `robots.txt` alone), not a partial gap, so it reads as a site-wide choice rather than an inconsistency.
